# Competitive Programming Mastery

A structured journey to build strong competitive-programming and coding-interview skills using Rust.

## Current phase

- Phase: Month 1 — Rust and problem-solving foundations
- Week: 1
- Lesson: Rust setup, variables, basic types, input and output
- Weekly commitment: 23 hours
- Primary focus: Competitive programming
- Secondary focus: Coding interview questions
- System design: Deferred until after the initial six-month phase

## Current assignment

Write a Rust program that reads three `i64` integers and prints:

1. Their sum
2. Their maximum
3. Their minimum

Print each answer on a separate line.

Also provide:

- Your Rust version
- Output from at least two test cases
- Any concept that remains unclear

Do not commit a copied solution. The purpose is to practise writing and understanding it yourself.

## Workflow

1. Attempt the assigned problem independently.
2. Record whether it was solved independently, with hints, or after an editorial.
3. Review correctness, complexity and Rust implementation.
4. Revisit selected problems after a delay.
5. Participate in timed contests once the foundations are ready.

## Repository structure

The repository starts deliberately small. New directories will be introduced only when they become useful.

- `src/` — current Rust program
- `PROGRESS.md` — current checkpoint and learning record
- `Cargo.toml` — Rust package configuration

Later, we will add topic, contest and reusable-template directories.

## Run locally

```bash
cargo run
```

## Guiding rule

A topic is not mastered because its explanation was read. It is mastered when the underlying idea can be recognized, explained and implemented independently.
